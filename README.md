## v1(상담교사편)에서 더한 것

- **월별 도서관 살림** — 3월부터 2월까지 학사력 순으로 그 달의 일과, 그 일에 쓸 프롬프트를 연결
- **저작권 살펴보기** — 학교도서관에서 자주 걸리는 10가지 상황별로 확인할 지점과 더 안전한 길
- **상황 칩** — 신규 발령 / 장서점검 / 수서·예산 / 협력수업 / 독서행사 / 북큐레이션 / 생기부 시즌 / 저작권 걱정
- **이어 쓰면 좋은 것** — 프롬프트 사이를 오가는 연결
- **개인정보 점검 강화** — 등록번호·바코드 탐지 추가, 대출 이력의 민감성 안내

## 기능

- **채우기** — 프롬프트 안의 `[대괄호]`가 자동으로 입력칸이 됩니다(446개). 채운 값은 브라우저에 남습니다.
- **개인정보 점검** — 붙여넣으면 이름·연락처·학교명·학번·등록번호 등을 찾아 표시하고 한 번에 가려 줍니다. 전부 브라우저 안에서만 처리되며 서버로 전송하지 않습니다.
- **프롬프트 직접 짓기** — 역할·맥락·과업·형식·제약·예시 여섯 칸. 공통 지시에 "서지를 지어내지 말 것"이 자동으로 붙습니다.
- **담아두기 / 검색 / 밝기 전환 / 인쇄 / 링크 공유**(`#프롬프트id`)

## 근거 자료

- 「학교도서관진흥법」 및 시행령 (제10조 학교도서관운영위원회 등)
- 경기도교육청 「학교도서관 진흥 시행계획」 (수서 절차, 자료구입비 3% 이상, 협력수업, 새로고침, 연구회, 지역서점 등)
- 교육부 「제4차 학교도서관진흥 기본계획(2024~2028)」
- 교육부 「학교생활기록 작성 및 관리지침」 및 2026 기재요령 (독서활동상황)
- 저작권법 제25조·제28조, 교육목적 저작물 이용 가이드라인
- 학교도서관 장서점검 및 제적·폐기 매뉴얼 (폐기 연 7% 이내 등)
- 독서로(read365.edunet.net) 운영 안내
- 교육부 「생성형 인공지능 활용교육 교사용·학생용 가이드라인」

41편에 어느 자료의 어느 대목에 기댔는지 표시해 두었습니다.

## 쓰기 전에

1. **책 제목·지은이·출판사는 AI가 가장 자주 지어냅니다.** 도서 목록, 추천 자료,
   참고문헌은 국립중앙도서관이나 서점 데이터베이스에서 한 권씩 대조하십시오.
2. **대출 이력과 학생 명단은 입력하지 않습니다.** 무엇을 빌렸는지는 그 사람이
   무엇을 궁금해했는지의 기록입니다. 이름을 지워도 학년과 특이한 관심사가
   겹치면 이미 특정됩니다.
3. 저작권은 목적과 공개 범위에 따라 판단이 달라집니다. 서지 않으면 하지 않거나,
   출판사에 문의하거나, 교육저작권지원센터에 확인하십시오.
4. 결재 문서, 학생 기록, 폐기 목록은 반드시 담당자가 검토하고 고쳐 씁니다.

## 구조

```
index.html    화면
styles.css    Editorial(pine) 디자인 토큰과 조판
prompts.js    프롬프트 86편 + 월별 살림 + 저작권 항목 + 안전 원칙 + 빌더 + 개인정보 규칙
app.js        검색·칩·필터·변수 채우기·점검기·빌더·달력
```

빌드 도구 없이 정적 파일 네 개로 돌아갑니다. 프롬프트를 더하려면
`prompts.js`의 `PROMPTS` 배열에 객체 하나 넣으면 됩니다.

```js
{
  id: 'p12', cat: 'pick', level: 1,
  title: '제목', desc: '한 줄 설명',
  tags: ['태그'], tools: ['claude'],
  body: `본문. 채울 자리는 [대괄호]로.`,
  tip: '쓰는 요령',
  care: '주의 (있을 때만)',
  source: '근거 자료 (있을 때만)',
  next: ['p01']   // 이어 쓰면 좋은 프롬프트 (있을 때만)
}
```

AI에게 "남기라고 지시하는 표시"(예: `[확인 필요]`)는 입력칸이 되면 안 되므로
`app.js`의 `NOT_VAR`에 등록합니다.
